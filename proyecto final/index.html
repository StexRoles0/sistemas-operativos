Simulador de segmentación paginada para un espacio lógico de 32 bits

Este programa divide una dirección lógica en segmento, página y desplazamiento, y muestra cómo una página se traduce a un marco físico dentro de una RAM direccionable de 232 posiciones.

Espacio lógico 232 bytes 4 GiB direccionables
Segmentos 8 3 bits para el selector de segmento
Páginas Configurables El tamaño de página define el desplazamiento
Objetivo Traducir Segmento + página + offset → dirección física

Configuración

Define el tamaño de página y los segmentos del proceso.

Segmentos del proceso

Cada segmento se divide internamente en páginas del tamaño elegido.

Catálogo de procesos

Selecciona un proceso base o agrega uno nuevo para cargar su distribución de memoria.

Agregar proceso

Crea un nuevo perfil de proceso para probar otro escenario de memoria.

Resultado de la traducción

La salida muestra el recorrido completo desde la dirección lógica hasta la física.
